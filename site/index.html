A 66-second Qwik cartoon

JavaScript Streaming

Bolt, the Qwik logo with rubber-hose arms and legs, renders a page on the server, streams the HTML to the browser in pieces, then streams the page's JavaScript in the background. When a click needs code that hasn't arrived yet, Bolt holds on to the click and sends that code first.

Out-of-order streaming with <Pending> is experimental in Qwik v2 (it needs experimental: ['pendingBoundary']). By default Qwik streams in order, flushing what it has before it waits.

How it was made

Pictures. Every frame is painted in code with p5.js and p5.brush, then rendered in headless Chrome. The animation kit is John Heibel's ClaudeAnimationBase.

Sound. The music and the 75 sound effects are synthesized in plain Node: plucked strings, marimba, glockenspiel, soft drums, no samples.

Story. Each picture was checked against the Qwik v2 source: the preloader queue, qwikloader and the out-of-order executor.
